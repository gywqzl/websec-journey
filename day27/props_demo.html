1. 元素对象：拿到「整个标签」，然后读它、写它

你 Day 14 就会这个：

document.getElementById('back')

它返回的不是一段文字，是那个元素本身（一整个 <a> 标签）。 拿到之后存进一个变量，习惯起名 el（element 的缩写，是我随便起的变量名，不是关键字，跟 Day 14 的 var 一个性质）：

var el = document.getElementById('back');   // el 现在就是那个 <a> 元素
el.href          // 读：这个元素的 href 值是什么
el.href = '/new' // 写：直接赋值，页面上的链接立刻变

这跟你学过的 el.value = 'x'（改输入框内容）、el.innerHTML = 'x'（改元素里的东西）是同一招，只是这次的属性名换成了 href。el.value / el.innerHTML / el.href 全是“元素上的一个属性”，读写方式完全一样。

2. URLSearchParams：把 ?a=1&b=2 变成能按名字查的表

你 Day 25 已经会 location.search（地址栏 ? 及后面那整截，是个字符串）。要从中取出某个参数的值，浏览器自带了一个小工具：

var q = new URLSearchParams(location.search);  // 把查询串解析成一张“名字 → 值”的表
q.get('a')       // 按名字查，返回 "1"
q.get('nope')    // 查不到，返回 null（不是报错、不是空字符串）

new + 名字 + 括号 = “造一个新的这种工具出来”（Day 14 你见过 var，这里是造对象，先照抄用法即可）。.get() 里的点号 = “用它的某个功能”，跟 .innerHTML 的点号一个意思。

3. ||：左边拿不到东西就用右边兜底

var name = q.get('nope') || '没传';   // q.get 返回 null，null 算“没东西”，于是取右边的 '没传'

|| 是 JS 里的“或”。用在这里的惯用法是兜底：左边是 null 或空字符串，就取右边的值。它不是 if 判断，是“取值时挑一个”。

4. jQuery：一个第三方 JS 库，只换了“找元素 / 改属性”的写法

jQuery 是别人写好放在网上的一个 .js 文件（老牌库，很多真实站点还在用）。页面里先引它，才能用它的功能：

<script src="jquery.js"></script>   <!-- 引进这个库 -->

它提供两个你今天要认出来的写法，跟你会的东西一一对应：

你会（原生 JS）jQuery 等价写法说明
document.getElementById('back')$('#back')$ 是 jQuery 提供的“找元素”函数；括号里写选择器字符串
el.href（读属性）$('#back').attr('href')attr = attribute（属性）的缩写
el.href = '/new'（写属性）$('#back').attr('href', '/new')两个参数 = 写；一个参数 = 读

选择器里那个 # 是 CSS 的写法，意思是“按 id 找”（#back = id 为 back 的元素；.back 则是按 class 找）。注意这个 # 跟地址栏的 #（fragment）没有关系，只是符号长得一样。

这一节没有可点的按钮（本地没放 jquery.js 文件）；等你在 PortSwigger 那个 lab 页面上按 F12 敲 $('#backLink').attr('href')，就是这条公式的活体验证。

5. document.domain：当前页面在哪个域名下

document 就是“你这一页的文档对象”——Day 25 的 document.write、Day 21 的 document.cookie 都是它的成员。.domain 是它的一个属性，值是当前页面的域名。location.href 则是当前页面的完整网址。
