## 三类监听地址

| 看到什么 | 谁能连 | 例子（我这台） |
|---|---|---|
| `127.0.0.1:端口` | 只有本机 | `127.0.0.1:3306`（MySQL） |
| `*:80` | 本机所有网卡，同网络的人能连 | `*:80`（Apache） |
| `某块网卡的 IP:端口` | 走那块网卡的人 | `10.255.255.254:53` |

实测对比（同一条命令，只换地址）：

```
$ curl -s -o /dev/null -w "%{http_code}\n" http://192.168.221.59/       -> 200
$ curl -s -o /dev/null -w "%{http_code}\n" http://127.0.0.1:3306/       -> 000
```

3306 只听 `127.0.0.1`，所以换成 eth0 的地址就连不上。

## `curl -v` 的行首三种

```
*   Trying 127.0.0.1:80...            <- curl 自己的旁白
> GET / HTTP/1.1                      <- 我发出去的
> Host: 127.0.0.1
> User-Agent: curl/8.18.0
> Accept: */*
>                                     <- 空行：告诉服务器「头结束了，下面是请求体」
< HTTP/1.1 200 OK                     <- 服务器回来的
< Server: Apache/2.4.66 (Ubuntu)
```

`-v` 的这些行走的是 stderr，所以想截取要写 `2>&1`，不然管道收到 0 字节。

## 今天纠正的三个说法

1. `HTTP/1.1` 是**协议版本**，不是我用的工具（工具是 curl，写在 `User-Agent` 里）
2. `Host` 是**我要访问的网站名**，不是我这边的地址
3. `User-Agent` 是**客户端自报身份**，不是「代理」（proxy 是中转服务器）

## 0.0.0.0 为什么不能当网址

`0.0.0.0` 是监听时的**占位符**，代替「本机所有地址」，管的是「我在哪个本地地址上收」，
不管「谁能来敲门」——那是网段、路由、防火墙的事。

地址本来是要唯一指向一台机器的，而 `0.0.0.0` 在**每台机器上都指它自己**，
写进网址别人只会打到他自己那儿，所以它不能当网址用。

坑：本机 `curl http://0.0.0.0/` 会回 200，因为本机把它当 `127.0.0.1` 处理了。
**能通 ≠ 成立。**

## 第 2 步：四个状态码，两对（11-07）

命令（都带 `-i`，把响应头也打出来）：

```
$ curl -i http://127.0.0.1/dvwa
HTTP/1.1 301 Moved Permanently
Location: http://127.0.0.1/dvwa/

$ curl -i http://127.0.0.1/dvwa/index.php
HTTP/1.1 302 Found
Cache-Control: no-store, no-cache, must-revalidate
Location: login.php

$ curl -i -X PUT http://127.0.0.1/
HTTP/1.1 405 Method Not Allowed
Allow: POST,OPTIONS,HEAD,GET

$ curl -i -X FOOBAR http://127.0.0.1/
HTTP/1.1 501 Not Implemented
```

| 对 | 区别（一句话） | 实测证据 |
|---|---|---|
| 301 / 302 | 301 被浏览器**记住**，下次不问服务器；302 不记，下次还问 | 少斜杠 → 301 补 `/dvwa/`；未登录 → 302 到 `login.php` |
| 405 / 501 | 405 = 地址在、但**不接这个方法**；501 = **不认识这个方法** | Apache 认识 PUT 但不给 `/` 用；`FOOBAR` 压根不认识 |

**坑（我踩过的）**：

1. `Allow` 头 **405 和 501 都有**，不能拿来区分两者。要看语义。
2. 缓存看的是**状态码**，不是 `Location` 长得像不像网址。301 的 `Location` 是绝对 URL，
   302 的是相对路径 `login.php`，但决定缓存的是 301 这个码本身。
3. 302 那条还额外带 `Cache-Control: no-store`——这是 DVWA/PHP 自己加的，不是 302 自带。
4. 把登录跳转的 302 改成 301 → 浏览器记住后**直接跳到目标页，跳过登录检查**。

`-i`（include）= 把响应头也打出来；`-X` = 手动指定方法。

## 我实际卡住的

今天没搞懂 0.0.0.0 具体的作用以及网卡和 ip 的关系，不过在研究和询问下都解决了，0.0.0.0 是一个通配地址或者说是占位符，意思是囊括本机上的任意地址。网卡相当于一栋楼的大门，而 ip 是这栋楼的门牌号，端口是里面的房间号。
